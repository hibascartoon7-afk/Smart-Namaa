## Notes

### Missing Data Policy

- Unmeasured variables must be stored as NULL.
- Missing values must never be converted to 0.
- Missing values must never be imputed.
- The decision engine may return partial decisions.
- Missing variables must be listed explicitly in the response.

### Units

- Moisture: m3/m3
- Soil Temperature: C
- EC: dS/m
