نظام NAMAA منصة زراعة ذكية تهدف إلى مساعدة المزارعين على اتخاذ قرارات الري بدقة أعلى وتقليل هدر المياه. تعتمد المنصة على دمج مصدرين من البيانات: قراءات المجسات الحقلية (رطوبة التربة، حرارة التربة، التوصيلية الكهربائية EC)، والبيانات الجوية (الحرارة، الإشعاع الشمسي، الرطوبة النسبية، سرعة الرياح).
تُعالَج هذه البيانات داخل محرك قرار (Decision Engine) يحسب التبخر المرجعي ET0 وفق معادلة FAO Penman-Monteith، ثم يحوّله إلى الاحتياج المائي الفعلي للمحصول ETc بضربه في معامل المحصول Kc المخزّن في قاعدة البيانات، ثم يدمج النتيجة مع رطوبة التربة وقواعد الري الخاصة بكل محصول ليصدر أحد ثلاثة قرارات: Irrigate أو Wait أو Insufficient Data.
تم تنفيذ النظام فعلياً على قاعدة بيانات Supabase مع Edge Functions لمعالجة البيانات، وواجهة مستخدم مبنية بـ React وTypeScript تتضمن لوحة مراقبة (Dashboard) تعرض القرارات والقراءات. صُمّم النظام ليدعم محاصيل متعددة عبر جداول معاملات بدلاً من تثبيتها في الكود، وبمعمارية قابلة للتوسع نحو نماذج التعلم الآلي والمساعد الزراعي الذكي.
